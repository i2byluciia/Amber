# AMBER 🧡

AMBER es un asistente personal inteligente diseñado para aprender, recordar y ayudar en el día a día.

El proyecto busca integrar **IA, automatización, voz, memoria, domótica y un homelab** en un único ecosistema personal.

AMBER crecerá progresivamente, empezando por un núcleo de IA y evolucionando hacia un asistente capaz de interactuar con servicios, dispositivos y el entorno del usuario.

> **AMBER — A personal AI assistant, built from scratch.**
